## 重点验证项

### 多轮节点上下文（I-09/I-10/I-11）——全链路实测通过

```
① "在 web 分组的节点上检查 sshd 进程是否在运行" → execute_command(ps aux|grep sshd, group=web) → 确认 → 真实执行
② "sshd 占用了多少内存"                              → ps aux|grep sshd|awk RSS 汇总，group=web 自动复用
③ "这台机器还剩多少内存"                              → free -h，上下文延续
```
- 第二轮**无显式目标**时自动复用上一轮节点（程序层 `Session.nodeContext` 保存并注入）
- I-11 验证新查询覆盖旧上下文（web → db 组切换正确）
