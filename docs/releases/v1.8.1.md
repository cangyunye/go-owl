# v1.8.1 变更记录

本版本包含 **3 个提交**，是 v1.8.0 的修复版本：修复剧本运行弹窗「目标节点」只显示部分节点、节点计数不正确的问题。

## 🐛 问题修复

### 剧本运行弹窗目标节点不全
- **根因**：`GET /api/v1/nodes` 不带 `page_size` 时服务端默认只返回 20 条（上限 100），而运行弹窗裸调该接口只取第一页——节点多时目标节点只列前 20 个、「全选」只选中这 20 个、分组徽标按第一页统计（排序靠后的分组甚至显示 0）。（3f5712c）
- **修复**：
  - 新增 `api.nodesAll()`：按 `meta.total` 以 `page_size=100` 翻页取全量节点；对「服务端钳制 page_size」与「未返回 total」两种情况都有兜底，避免 helper 自己只取一页
  - 剧本运行弹窗的目标节点列表、全选、分组计数改为基于全量节点
  - 同款缺陷一并修复：告警调试弹窗的节点下拉（原写死 `page_size:100`）、任务页节点选择器（原 `page_size:500` 会被服务端钳到 100，其「节点总数」也随之偏小）
- **测试**：
  - Go 回归断言：运行弹窗不得裸调节点接口、其余节点选择器必须走全量接口
  - 新增 E2E `test/e2e_issue11_playbook_run_all_nodes.py`：140 节点下校验目标节点 140 个、全选 140、分组徽标 90/50、搜索过滤 90、提交的 `target_nodes` 140 个、告警调试下拉 140 项

## 📝 文档与其他

- 归档该问题的 dts 档案，含 Playwright 截图与修复前后输出快照（530a73c）
- E2E 脚本用后清理种子剧本（剧本库是全局共享路径，不在 e2e 独立 db 内）（04e9ffd）
