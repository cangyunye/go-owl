# v1.5.0 变更记录

本版本包含 **37 个提交**，主线是 AI 链路（function calling、流式、会话持久化、审批与安全拦截）与监控告警自愈闭环，并把 AI 面板与输入补全带进 TUI。

## ✨ 功能增强

### AI 内核
- **统一 LLM 客户端**：收敛为 `internal/ai` HTTPModel，CLI 与 Web 双宿主共用一套实现（afee611）
- **原生 function calling**：Agent 工具循环加深，工具调用不再靠文本解析（39032e7）
- **流式输出全链路**：内核 SSE → Web SSE 端点 → CLI 打字机逐字输出（68a0bda）
- **会话持久化**：重启不丢上下文，双宿主共用 `ai_sessions` 表（151021e）
- **跨端续聊**：CLI 会话可导入 Web 端继续对话（0bb3c14）
- **路由闲聊兜底**：场景路由失败时降级为直接对话，不再直接报错（2a6fe2d）
- **用户级调用限额**：每用户滑动窗口限流（6fe2e2d）
- **高危操作审批工作流**：确认门可挂起并转为持久审批单（ac50531）
- **命令安全拦截下沉内核**：黑名单硬拦截 + 低危白名单分级确认，三端一致（4aa9d13）

### 监控与自愈闭环
- **失败自动回滚**：rollback 执行路径，逆序回滚已成功步骤（0494d5c）
- **恢复闭环验证**：处置完成后定向采集核查疗效（36eeda2）
- **疗效未确认自动换方案**：自动改试未尝试过的对策（8ea6818）
- **告警绑定纳入闭环验证**：绑定成功后定向核查疗效（af1f0ac）
- **not_recovered 通知 + 疗效计数排序**：闭环反应层（8377976）
- **AI 处置上下文增强**：带上历史同类处置、告警前变更、相关告警（e5739ee）

### 权限与审计
- **节点/分组范围授权**：用户只能操作授权范围内的节点（6c230a2）
- **操作来源标记**：AI 发起的执行带 origin，可整体回溯（dc6d5e0）

### TUI
- **AI 面板对话式布局**：自动聚焦 + textarea + 对话流渲染（d152189）
- **AI 面板流式输出**：delta 实时渲染与工具进度（b98c8f9）
- **AI 面板斜杠命令**：复用 SlashMenu 与跨端共享命令目录（dcba1b7）
- **输入补全扩展**：Exec 面板节点/分组/标签补全（c054bbd）；补全模式抽成共享包 `tui/complete` 并扩充到 File 面板（172b71d）

### 技能与文档
- capability 能力录入技能：触发词 + 四步工作流 + 元数据 schema（b9061fb）
- 能力库与 AI 匹配规范设计稿：统一能力抽象、双通道元数据、四级降级链（1ced95c）

- 断点续传增加前缀一致性校验，杜绝拼接损坏（93f3830）

- 中转站删除/清空按钮可见性与筛选行紧凑化（3e7dbf4）
