# v1.9.0 变更记录

本版本包含 **33 个提交**，主线是 **Web 控制台的内建标签页**：一个标签进一个视图（节点管理、剧本管理、系统设置、告警中心各占一个标签，也可以多个标签同时停在节点管理），围绕它配套做了页面资源作用域、会话类页面保活、连接与传输减负，以及执行页的分离方式运行与终端限额。

## ✨ 功能增强

### 内建标签页（M1 / M2）
- **标签栏**：顶栏下方新增标签栏，每个标签承载「一级导航 + 侧栏子菜单 + 详情」整条上下文
- **导航语义**：点侧栏复用已打开的同视图标签（保住里面的筛选），`Ctrl/⌘+点击` 或**中键**才新开标签 —— 因此可以同时开两个「节点管理」标签各停在不同分组
- **标签内下钻**：列表 → 详情（节点详情 / 任务详情 / 终端 / SFTP）在原标签内进行；停在深层路由时点同级导航会新开标签，不会把会话页挤掉
- **嵌套上下文入 URL**：节点页 `?group=&q=&status=`、剧本页 `?cat=&q=` 写进地址栏并显示在标签标题上（如「节点管理 · web · "db"」），可收藏、可分享、刷新不丢
- **标签操作**：`×`/中键关闭、右键菜单（关闭其他/右侧/全部）、拖拽排序、上限 8 个；快捷键 `Alt+T` / `Alt+W` / `Alt+PageUp`/`PageDown`
- **刷新恢复**：标签集合与激活项持久化，刷新后自动恢复
- **面板随页面**：侧栏面板归属当前标签，详情页不再残留上一页的分组面板

### 会话类页面保活（M3，同文档保活）
- **终端**：切标签不再掐断 shell —— 容器摘除、WebSocket 与 xterm 实例保留，切回是同一 DOM、滚动缓冲保留、无需重连
- **SFTP**：上传/下载在失活期间继续跑（只暂停界面更新），切回重绘队列与目录
- **AI 助手**：流式回答继续累积，失活期间产生的消息挂起、切回补渲染
- **剧本管理**：运行在服务端继续，广播在失活期被门控，切回补拉列表与详情

### 分离方式运行（执行页）
- 命令可在**节点侧** `setsid nohup` 后台执行，输出写日志文件，服务端只记 pid 与日志路径
- **关页面、刷新、甚至 owl-serve 重启都不影响它跑完**；终端头部「查看分离输出」可看进程状态与日志尾部
- 不依赖节点安装任何代理（只用节点自带的 `sh/setsid/nohup`）

### 终端限额（系统设置可调）
- `terminal.idle_timeout_min`（默认 30）：终端连续无任何输入/输出超过阈值自动断开并释放会话与远端 shell；正在产出的命令不会被打断
- `terminal.max_per_user`（默认 5）：每用户并发终端上限，超出后拒绝新建并给出提示

### 其他
- **执行页可拖拉分隔条**：命令编辑器与输出终端之间可拖动分配高度，记忆在本地、双击复位
- **SSH 认证失败报错可诊断**：报错标明使用的账号并提示排查方向（用户名/密码/密钥、该用户是否允许登录）

## ⚡ 性能

- **传输层减负**：全局 gzip（WS/终端/SSE 显式跳过）+ 静态资源 ETag 与缓存头（命中即 304）。实测节点列表 JSON 21.3KB → 1.1KB，`api.js` 26.2KB → 6.4KB
- **全量节点客户端共享缓存**：按 30s TTL + 并发去重共享，多个标签打开选择器只拉一遍；节点增删改/导入自动失效
- **共享 WS 总线**：全应用一条 WebSocket，页面订阅共用（此前每页各建一条 + 各自 3s 重连）
- **增量取输出**：任务列表支持轻量返回（只回状态与 `output_len`），输出走 `?offset=&limit=` 字节游标只补缺失尾部；`task_output` 广播附带行起始偏移供客户端维护精确游标

## 🐛 问题修复

- **节点搜索搜不到**：搜索端点不匹配节点 `id`（节点常靠 id 辨识，如 `wsl-kube` 的 name 是 "WSL Ubuntu"）；列表端点则完全没有 `q` 参数，导致执行页左侧节点面板的搜索一直「输入没反应」
- **终端/SFTP 页面上下变窄**：壳层残留了一个静态 `.view-container`，与每标签容器同为 `flex:1`，把主区高度对半劈开（900 高窗口里内容区只有 409），并造成重复 id
- **切页资源残留（M0）**：文件页 5 秒轮询的 `stopAutoRefresh` 全仓无调用点、节点页/设置页的 document keydown 每次挂载加一条、告警页递归轮询无取消句柄、AI 流式回答不可中止、body 级浮层跨页残留 —— 统一改为注册到页面作用域，导航切走即释放
- **壳层其它**：节点行中键在新标签打开详情、详情页清空面板、登出清空标签集合
