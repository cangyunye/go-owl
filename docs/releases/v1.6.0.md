# v1.6.0 变更记录

本版本包含 **39 个提交**，是一次代码审查后的优化修复版本：把告警数据接进 AI/CLI/TUI、系统性做性能优化（连接池、索引、实例复用、并行探测），并为指标与历史数据补上保留期清理。

- WebExecutor 告警数据实现与装配（86a7b9e）

### 存储治理
- **指标清理后自动 VACUUM** 回收磁盘，清理周期与采集间隔运行期可调（9c071e6）

- admin 数据库统计与手动 VACUUM 端点（df6ff87），设置页新增监控卡与数据库统计卡（62cc197）
- 执行日志批次的占用汇总与过期清理（54c3cc4），admin 手动 + 每日定期清理（426a89a）
- owl.db 历史表接入每日定期清理（`history.retention_days`）（f80e253）
