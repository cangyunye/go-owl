# v1.7.0 变更记录

本版本包含 **7 个提交**，聚焦 AI 链路输出治理与 Web 控制台的一批可用性修复，并放开运维角色的本地剧本管理权限。

## ✨ 功能增强

### AI 链路
- **上下文治理 + 调用合并**：按 P2/P3 计划压缩上下文并合并往返，降低 token 与延迟（df4f44a）
- **交互输出治理**：清理进度噪音，修复管道场景下的 ANSI 乱码（b030776）

### Web 控制台
- **运维角色可保存/删除本地剧本**：剧本管理不再局限于 admin（2e5c4b4）
- **命令执行页**：中转站下拉框箭头平铺；新增「不输出节点响应」开关，批量执行时抑制超长回显（0ffd141）
- **登录页与导航栏**：增加仓库地址与作者签名（9c2e320）

## 📝 文档与其他

- 归档中转站下拉框 / 剧本权限 / 批量输出 / 签名问题的 dts 档案（0946d91）
