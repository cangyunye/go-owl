# v1.4.1 变更记录

本版本包含 **31 个提交**，聚焦三大主题：剧本管理页主从分栏重构、文件传输中转站工作台、执行链路的可靠性修复。

## ✨ 功能增强

### 剧本管理
- **主从分栏重构**：左侧剧本列表 + 右侧详情卡（元信息 / 任务 / YAML 语法高亮），点行即选、不再弹窗；Library Path 收进工具栏折叠行，不再独占一张卡片
- **视图切换**：剧本列表支持 表格 / 卡片 两种视图（选择持久化），分类彩虹色贯穿侧栏、列表与详情
- **运行弹窗重做**：节点 / 分组胶囊多选（带在线状态点、全选 / 清空）、Extra Vars 键值行编辑、中转站文件折叠区，与命令执行页同一套设计语言
- **创建向导瘦身**：5 步合并为 3 步（可点击跳转），任务卡按动作类型渲染专属字段（command 命令框、upload src/dest 等），支持拖拽与按钮排序
- **运行详情增强**：新增任务进度条与「仅看失败」筛选；运行历史 / 详情全宽渲染，步骤结果表不再拥挤
- **运行历史真分页**：服务端分页替代固定最近 50 条

### 文件传输
- **中转站工作台**：左右两列布局——传输表单与传输记录纵对齐居左，筛选条件与中转站居右；文件名优先展示、文件类型图标、批量删除（d06fc90、7f5d98f）
- **服务端分页**：传输记录 / 任务详情 20 条每页，列表限高不再把中转站顶出屏幕
- **目标节点防护**：未选任何分组 / 标签时全量执行需确认，超 50 节点二次确认

### 命令执行
- 任务终态按 record 对账，兜住 WS 断线窗口内丢失的完成消息；收齐终态时用任务记录回填缺失的实时输出
- 重试进度实时播报到终端
- `command_timeout` 兜底：清空输入不再悄悄变成「无超时」（避免远端挂死导致节点永久停在执行中）

### 告警中心
- 自定义告警配置：检查命令 + 阈值规则 + 处置指令（剧本）选择
- 告警规则支持触发范围（节点 / 分组）与一键调试执行

### 界面
- 设置监控面板与用户管理页统一 Panel 设计系统
- 浅色主题重配色为「青瓷纸白」，修复浅色适配缺口

## 🐛 问题修复

- 运行状态徽章补齐配色：running / completed / failed / cancelled 等 8 种状态此前全部渲染为无色文本
- 传输列表间歇性丢失：SQL 层过滤任务前缀 + 轮询失败保留上次数据，不再闪现「暂无记录」
- 传输状态如实呈现：批量提交只表示已排队（202），不再声称「完成」；同名记录可区分
- WebSocket 慢客户端改为主动断开，不再静默丢消息
- 输出采集超长行不再静默截断
- 启动时对账悬挂的执行任务与告警绑定运行记录
- 节点分组统计只覆盖前 20 个节点（现按 meta.total 翻页拉全量）
- 通知渠道窄下拉原生箭头恢复，修复三角压住选中文字
- 构建：task 构建 owl-serve 补充版本注入（SERVE_LDFLAGS）

## ⚡ 性能

- 执行终端逐行追加渲染，不再对整段输出重序列化（几千行输出下 O(n²) 卡顿消除）

## 🧪 测试

- 新增 UI 契约测试：剧本页布局与交互契约、文件传输分页 / 委托 / 防护契约、执行页超时与对账契约
- 新增命令执行输出链路 E2E 冒烟脚本
