# v1.8.0 变更记录

本版本包含 **6 个提交**，新增 **SFTP 文件浏览器**：在 Web 控制台里直接浏览节点文件系统、上传下载、递归同步目录，不再依赖中转站绕行。

## ✨ 功能增强

### SFTP 文件浏览器（M1–M6）
- **后端 API（M1–M3）**：目录列表 / 新建 / 重命名 / 删除、流式下载、按冲突策略上传（覆盖 / 跳过 / 重命名），前缀 `/api/v1/sftp`（27b1efb）
- **前端页面（M4）**：目录浏览、面包屑导航、新建 / 重命名 / 删除 / 下载，节点入口与「文件管理」列（e477799）
- **队列与冲突处理（M5）**：拖拽上传、传输队列进度、重名冲突弹窗与批量决策（160edee）
- **递归同步（M6）**：文件夹拖入递归同步——同名目录合并、不删多余文件，重名文件逐个弹窗确认（4cdcd7f）

### 设计文档
- SFTP 文件浏览器设计稿与设计文档索引（1e23b08）

## 说明

- 该能力与既有的中转站（staging）传输互补：中转站负责「先落地再分发」，SFTP 浏览器负责「就地查看与整理」。
- 设计文档见 [SFTP 文件浏览器设计稿](https://github.com/cangyunye/go-owl/blob/main/docs/design/06_SFTP_FILE_BROWSER.md)。
